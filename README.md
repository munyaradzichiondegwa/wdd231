This repository contains assignments, exercises, and the final personal project developed as part of the course. :contentReference[oaicite:1]{index=1}

---

## 🚀 Project Overview

In this course you’ll learn and practice:

- 💡 **Responsive Web Design** – Make layouts that adapt across devices.
- 🧠 **Semantic and Accessible HTML** – Use meaningful markup for structure and accessibility.
- 🎨 **CSS Styling & Layouts** – Master positioning, Flexbox, and responsive techniques.
- 🔄 **JavaScript Interactivity** – Add dynamic behavior with DOM manipulation.
- 🌐 **Web APIs & JSON** – Fetch and display remote data.
- 📦 **Deployment** – Host your finished project on GitHub Pages.

You’ll complete weekly exercises and submit a **personal project** demonstrating your skills by building an interactive, multi‑page website that runs in a browser. :contentReference[oaicite:2]{index=2}

## 🛠 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/munyaradzichiondegwa/wdd231.git
   cd wdd231
````

2. **Open any project HTML file in your browser:**

   * Simply double‑click the `.html` file (e.g., `project/index.html`) or,
   * Serve using a local server for better testing (optional):

     ```bash
     npx http‑server .
     ```

3. **View in browser** to explore your site and interactive features.

> No build tools are required — this repository uses plain HTML, CSS, and JavaScript.

## 📌 Final Project Requirements (Typical for WDD 231)

Your personal project should:

* Include **multiple pages** with common navigation.
* Be **responsive** on mobile and desktop screens.
* Use **JavaScript** for dynamic content and user interaction.
* Leverage browser APIs or fetch data from external sources.
* Follow **semantic markup and accessibility best practices**.

You’re encouraged to showcase your creativity while meeting functional requirements. ([Amelia Rose][1])
